# Architecture decision records

`Accepted` in an ADR means that the repository adopted the stated design direction; it is not a release, support, or runtime-acceptance status. Only decisions exercised by the frozen `synex_core` tree fall inside the accepted Production-Beta boundary. Groups is Experimental Alpha; decisions about it, accounts, entities, control, bridges, UI, Notify, Security, or any later module remain outside Core acceptance and may be superseded before those components receive separate release decisions.
